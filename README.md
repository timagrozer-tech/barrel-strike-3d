# VOID FRONTIER 3.0 — Космический розыск СОЧ

Вертикальный космический шутер на HTML5 Canvas (чистый JavaScript, Web Audio, офлайн PWA, Android APK через Capacitor).
Вымышленная комедийная история: сотрудник группы розыска СОЧ преследует Архитектора Бездны через четыре космические операции, а затем — Капитана Ухмылку (операция 5).
Интерфейс — дизайн №2 «Военный штаб и розыск» (`www/css/ui.css`, `www/js/ui.js`).

## Что внутри
- **Кампания «Дело № 000»** — 4 операции (Орион → Азалия → КПП-7 → Бездна), улики, брифинги, мини-боссы, флагман Архитектора, 3 концовки (одна секретная); операция 5 — стелс-крейсер Капитана Ухмылки.
- **Бездна ∞** — бесконечные волны, перки каждые 3 волны, мини-босс каждые 5, флагман каждые 10.
- **Парад Дебилов** — все 8 мини-боссов подряд.
- **Архив штаба** (стелс) и **Нижний рынок** (6 контрабандных модулей) — необязательные.
- 6 типов врагов: разведчик, перехватчик, штурмовик, снайпер (прицельный луч), носитель дронов, бомбардировщик (бомбы с радиусом взрыва). Формации, элита, бонусы.
- 8 мини-боссов с 2 фазами и предупреждаемыми спец-атаками; Архитектор — 4 фазы, 4 разрушаемые турели, раскрывающиеся крылья, лучи, гравитационные кольца.
- Эволюция корпуса 1–5 (отдельно от оружия) с предпросмотром в ангаре; оружие 1–10 с новыми потоками огня на 3/6/9; дроны, самонаводящиеся ракеты.
- Верфь: 8 кораблей классов C/B/A/S/Легенда; 28 достижений; звания пилота; награда дня; испытание дня с модификаторами.
- Настройки: звук (общий/эффекты/музыка + музыка боёв/боссов/штаба), качество графики (авто/низкое/среднее/высокое), размер кнопок, тип управления, тряска, вибрация, экспорт/импорт профиля.

## Запуск
```bash
python3 -m http.server 8081 -d www     # открыть http://localhost:8081
```
Для установки как PWA на Android нужен HTTPS-хостинг папки `www/`.

## APK через GitHub
Каждый push в `main` или `void-frontier` запускает `.github/workflows/android.yml`: веб-тесты в Chromium → сборка APK (Capacitor 7, JDK 21).
Готовый файл: вкладка **Actions** → последний запуск → артефакт **VOID_FRONTIER_APK**. APK также публикуется как GitHub Release (прямая ссылка для телефона).
Подписанный release-APK собирается, если заданы секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`; иначе — debug-APK (устанавливается вручную, «из неизвестных источников»).
