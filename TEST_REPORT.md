# VOID FRONTIER 2.1 — отчёт о проверке (24.10.2026)

Все тесты запускались в Chromium (Playwright) через **реальный http-сервер** (`python3 -m http.server`), а не встроенный HTML — то есть загрузка графики по сети и service worker проверены.

| `npm run check` — синтаксис всех JS-модулей и sw.js | OK |

### Что покрывает full.py
- **Миграция реального сохранения 1.5** (`vf02` без версии): кредиты, оружие, корабль, дроны, ракеты, контрабанда, дела, старые концовки и настройки сохранены; `saveVersion=2`; уровень корпуса = прежняя визуальная ступень (4); создан резерв `vf02_backup_v1`; повторная загрузка стабильна; экспорт → импорт профиля; мусорный код отклоняется.
- **Кампания целиком**: 4 брифинга → бой → враги → правильный мини-босс каждой операции → его 2-я фаза → итог и разблокировка следующей операции → перехват → Архитектор → фазы 2/3/4 и крыльевые турели → выбор концовки; все 3 концовки, включая секретную.
- **Ангар**: эволюция корпуса 1→5 (5-я модель загружена), бонусы HP/дрона, предпросмотр ступени, оружие/дроны/ракеты, покупка SPECTER, сохранение покупок.
- **Штаб → нижнее КПП → Нижний рынок → покупка → возврат → завершение штаба**; влияние контрабанды на бой (+18% урона); стартовая улика из архива.
- **Пауза/продолжение**, **Бездна** (перк на 3-й волне, мини-босс на 5-й, Архитектор на 10-й, продолжение после него, гибель → экран итогов, рекорд волны), **Парад Дебилов** (все 8 мини-боссов → победа).
- **2.1**: миграция владения кораблями, покупка и выбор кораблей (классы A, B), блокировка легенды по званию, способности VALKYRIE/BASTION/ARCHON, достижения, награда дня (один раз в день), звание, испытание дня до 6-й волны, прокрутка ангара.
- **Вьюпорты 360×720, 390×844, 412×915**: заставка без прокрутки, нет горизонтального переполнения, кнопка «В БОЙ» видна, canvas без искажения пропорций, кнопка бомбы в пределах экрана.

Тесты ускоряют прохождение (задают HP/таймеры через JS), но вызывают настоящие функции игры.

## Что НЕ проверено
- Реальные Android-устройства: производительность на GPU телефона, сенсорное управление пальцем, звук после сворачивания, нагрев/батарея. FPS выше получен в программном рендеринге без GPU и не является гарантией 60 FPS на телефоне.
- Сборка APK не выполнялась в этой среде (нет доступа к Android SDK/npm-реестру); она выполняется GitHub Actions. Установка APK на телефон не проверялась.
- Баланс сложности оценён расчётно и по коротким прогонам, а не долгими ручными прохождениями.
- Права на коммерческое использование фото Архитектора и арта из концепт-листов не проверялись.
