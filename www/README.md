# VOID FRONTIER 1.3 — КОСМИЧЕСКИЙ РОЗЫСК СОЧ

**Основная игра — вертикальный космический шутер.** Штаб и Нижний рынок остаются дополнительными миссиями.

## Сюжет
Ты — персонаж фантастической вселенной, сотрудник штабной группы розыска самовольно отсутствующих (СОЧ). Вымышленный антагонист «Архитектор Бездны» покинул часть и улетел на секретном флагмане. Игрок собирает улики по делу № 000, уничтожает перехватчиков и помощников беглеца, открывает его маршрут и выходит на финальное столкновение. Образ антагониста использует предоставленное изображение как игровой референс; сюжет не утверждает ничего о реальном человеке на фото.

## Четыре полноценные операции в прототипе
1. Орбита «Орион»: Ебло Утиное (мини-босс).
2. Туманность «Азалия»: Лох Цветочный (мини-босс).
3. Станция «КПП-7»: Заминированный Тапок (мини-босс).
4. Сектор «Бездна»: Я Кавказ (мини-босс), затем Архитектор Бездны (главный босс).

Игрок собирает до трёх капсул телеметрии в космосе. После победы над помощником открывается следующий сектор и начисляются кредиты. Лучший счёт и разблокированные операции сохраняются локально в `vf02` — старый прогресс на рынке и по кораблям не удаляется.

## Две необязательные активности
- **Архив штаба**: собери три материала, пройди мимо патрулей. После первого успешного прохождения в каждой космической операции ты стартуешь с одной уликой.
- **Нижний рынок**: проход через нижнее КПП, торговцы, охрана, контрабандные улучшения, облава. Всё из версии 1.2 сохранено.

## Управление
- Во время космической операции: веди корабль одним пальцем, стрельба автоматическая. Есть бомбы и способности «Alt+Tab» и «Excel завис».
- В штабе и на рынке: касание пола для перемещения.

## Запуск
Открой `index.html` или размести папку на HTTPS-хостинге. Можно использовать отдельный `VOID_FRONTIER_1.3_QUICKPLAY.html` для запуска одним файлом (Android может ограничивать локальные сохранения `file://`).

Включён PWA manifest и сервис-воркер. Проверка установки и производительности на физическом Android ещё требуется.
